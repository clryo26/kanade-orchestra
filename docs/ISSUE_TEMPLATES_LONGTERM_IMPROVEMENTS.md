## Issue 1: Frontend Script読み込み順依存の可視化と検証

### 目的

- script直列読み込みの順序依存を検知し、実行時エラーを未然に防ぐ。
- 新規機能追加時の読み込み順回帰を防止する。

### 受け入れ条件

- 読み込み順チェックがCIで実行される。
- 依存順不整合時にCIが失敗する。
- チェック対象に主要ロード順が含まれる。

### 作業手順

1. 現行ロード順を [src/index.html](src/index.html) と [src/static/js/app.js](src/static/js/app.js) から棚卸しする。
2. 依存順チェック用スクリプトを scripts 配下に追加する。
3. package scripts に検証コマンドを追加する。
4. CIに検証ステップを追加する。
5. 手順を [docs/LOCAL_TEST_SETUP.md](docs/LOCAL_TEST_SETUP.md) に追記する。

### 完了定義

- ロード順不整合の意図的再現でCIが失敗する。
- 正常順でCIが成功する。
- ドキュメントに運用手順が反映済み。
