# PRODUCTION_RELEASE_CHECKLIST

## 記録欄

- 実施日:
- 実施者:
- 対象ブランチ/コミット:
- Cloud Run リビジョン:
- 判定: 実施可 / 保留

## 1. Cloud Run

- [ ] Cloud Run サービス名を確認した
- [ ] デプロイ先リージョンを確認した
- [ ] 最終反映リビジョンを記録した
- [ ] `CORS_ORIGINS` が本番 URL に限定されている
- [ ] `DATABASE_URL` が本番 DB を指している
- [ ] `GCS_BUCKET` が本番バケットを指している
- [ ] 起動確認（`/api/health` など）を実施した
- [ ] 起動直後ログに異常がない

## 2. PostgreSQL / DB

- [ ] 本番 DB 接続確認を実施した
- [ ] マイグレーション適用状態を確認した
- [ ] テーブル件数/主要データをスポット確認した
- [ ] バックアップ取得時刻を確認した
- [ ] 復元手順を確認した

## 3. Cloud Storage / GCS

- [ ] 本番バケット名を確認した
- [ ] CORS 設定が本番向けになっている
- [ ] サービスアカウント権限を確認した
- [ ] 署名 URL 生成を確認した
- [ ] 録音アップロード導線を確認した
- [ ] 楽譜 PDF 閲覧導線を確認した

## 4. 管理機能

- [ ] 管理者ログインできる
- [ ] 練習予定管理画面が表示される
- [ ] 演奏会管理画面が表示される
- [ ] 録音管理画面が表示される
- [ ] 楽譜管理画面が表示される
- [ ] 団員管理画面が表示される
- [ ] 支払状況画面が表示される

## 5. 団員画面

- [ ] 団員ログインできる
- [ ] 練習予定一覧を表示できる

- [ ] 楽譜一覧を表示できる

## 6. iPhone / PWA

- [ ] iPhone Safari で URL を開ける
- [ ] レイアウト崩れや横スクロールがない
- [ ] ホーム画面追加できる
- [ ] PWA 起動時に主要導線が使える
- [ ] 画面遷移後に戻る操作ができる

## 7. セキュリティ

- [ ] `.env` / credentials / 秘密鍵の混入がない
- [ ] 管理者専用 API の権限制御を確認した
- [ ] 不要な debug エンドポイントが無効
- [ ] CORS が過剰に開放されていない
- [ ] 監査ログまたはアクセスログを確認した

## 8. バックアップ

- [ ] DB バックアップ最新世代を確認した
- [ ] 録音・楽譜データのバックアップ方針を確認した
- [ ] 復旧担当者と連絡手段を確認した

## 9. ロールバック

- [ ] Cloud Run のロールバック先リビジョンを特定した
- [ ] DB ロールバック方針を確認した
- [ ] 障害時の判断基準（戻す/継続）を共有した

## 10. 障害時対応

- [ ] 障害一次切り分け手順を確認した
