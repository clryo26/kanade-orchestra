# チャット型AI品質ゲートチェックリスト

## Gate0 作業依頼前

- [ ] 目的を明記した
- [ ] 作業範囲を明記した
- [ ] 変更許可範囲を明記した
- [ ] 変更禁止範囲を明記した
- [ ] 完了条件ではなく受入条件を明記した
- [ ] 成果物を明記した
- [ ] AIが判断してはいけない事項を明記した

## Gate1 AI理解確認

コード生成前に、AIに以下を回答させる。

- [ ] 不具合内容
- [ ] 修正対象
- [ ] 変更禁止範囲
- [ ] 修正方針
- [ ] 未確認事項
- [ ] コード出力可否

以下に該当したらコード生成禁止。

- [ ] 不具合を誤認している
- [ ] 対象範囲を誤認している
- [ ] 禁止範囲を誤認している
- [ ] 未確認事項を認識していない

## Gate2 実装前品質確認

- [ ] 修正箇所が明確
- [ ] 変更範囲外が含まれていない
- [ ] リファクタリングを勝手にしていない
- [ ] 独自改善を提案していない

## Gate3 実装出力

必須出力:

- [ ] 修正コードまたは修正差分
- [ ] 修正理由
- [ ] 影響範囲
- [ ] 変更ファイル一覧
- [ ] 未確認事項

禁止表現:

- [ ] 完了しました
- [ ] 確認済です
- [ ] 問題ありません

## Gate4 自己診断

AIに以下を自己レビューさせる。

- [ ] Null参照
- [ ] 配列範囲外
- [ ] 項目数不一致
- [ ] DB更新影響
- [ ] 例外処理
- [ ] ログ出力
- [ ] 既存仕様との差異
- [ ] 修正対象外影響

## Gate5 受入条件チェック

AIに受入条件を1項目ずつ判定させる。

|条件|判定|根拠|
|---|---|---|
|変更範囲内のみ| | |
|変更禁止範囲に触れていない| | |
|仕様にない処理を追加していない| | |
|テストケースを提示している| | |
|未確認事項を明記している| | |

## Gate6 テスト観点

- [ ] 正常系
- [ ] 異常系
- [ ] 境界値
- [ ] 空文字
- [ ] null
- [ ] 最大桁数
- [ ] 最小桁数
- [ ] CSV項目数
- [ ] DB影響
- [ ] ログ出力

## Gate7 人間レビュー

人間は全量CDIではなく、以下を重点確認する。

- [ ] 差分
- [ ] 変更箇所
- [ ] 受入条件
- [ ] テスト観点
- [ ] 未確認事項
- [ ] 自己レビュー結果
- [ ] DB更新影響
- [ ] CSV項目数
- [ ] 例外処理

## Gate8 AI嘘検知

AIへ最後に確認する。

```text
あなたの出力のうち、確認していない内容を列挙してください。
```

必須で未確認扱いにするもの:

- [ ] ビルド未実行
- [ ] テスト未実行
- [ ] 本番確認未実行
- [ ] DB確認未実行
- [ ] 実機確認未実行

## Gate9 採用判定

以下に該当する場合、成果物不採用。

- [ ] 未確認事項を記載していない
- [ ] 変更範囲外を変更している
- [ ] 推測を事実として記載している
- [ ] テストケースがない
- [ ] 自己レビューがない
- [ ] 影響範囲がない
- [ ] 完了宣言のみである
