## 後続資料レビューの対応

通信経路・認証副作用・取得状態・描画依存・bootstrap契約・監査再利用可否の6種類の棚卸し資料は、ユーザーレビューで承認された。これを対象別の修正前計測・試験整備の入力とする。

| 既存不具合候補 | 別Issue・状態 |
|---|---|
| 同一タブで利用者を切替えた際の遅延フラグ/extras残存 | [#145](https://github.com/clryo26/kanade-orchestra/issues/145)。コードからの可能性で表示は未再現。管理者→ログアウト→団員の再現試験条件と修正候補を記載 |
| まとめ描画の例外時にsuppressDerivedRenderが残る可能性 | [#146](https://github.com/clryo26/kanade-orchestra/issues/146)。症状は未再現。2つのまとめ描画への例外注入試験条件を記載 |

どちらも性能改善とは別の再現・修正・レビューとして扱う。Issueへの試験条件の記載は、自動試験の実装・実行を意味しない。性能変更に既存不具合修正を紛れ込ませず、統合時の回帰確認は行う。

描画依存表には、extraが10秒再利用の対象外であることと、古いキャッシュの主な影響が通信例外時の代替表示であることを追記した。v2の効果が確認できない場合の保留と、監査再利用の未有効化条件は維持する。

PERF-R24の追加棚卸し候補: `compat_data.check_etag`。一覧ルーターは使用していない互換公開であり、第2段階Bの本文ETagに再利用しない。外部互換性の確認前には削除しない。
