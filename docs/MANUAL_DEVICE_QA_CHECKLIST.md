## 7. チューナー（実験室・システム管理者のみ）

設計と調整値は `docs/TUNER_DESIGN.md` を参照。PC の自動試験（疑似マイク）では iPhone Safari の挙動を確認できないため、以下は実機で確認する。

準備: システム管理者でログインし、「システム管理」→「実験室」→「チューナー」。音源は実楽器、またはチューナーアプリ等の基準音（440 Hz と 442 Hz）。

### 7-1. 初回起動・停止・再開（最小構成、最初に確認する）

- [ ] Safari の Web サイトデータを削除した状態で「チューナー」を1回タップすると、許可を求められ、許可後に測定が始まる（「タップして測定を再開」が出ない）
- [ ] 測定中、アドレスバー付近にマイク使用中の表示が出る
- [ ] 「実験室」に戻るとマイク使用中の表示が消える
- [ ] 再度「チューナー」をタップすると測定が再開する
- [ ] ホーム画面に戻る（バックグラウンド）とマイク使用中の表示が消え、Safari に戻ると自動で再開するか「タップして測定を再開」が表示される（どちらでも可。表示された場合は押して再開できる）
- [ ] 戻る／進むでチューナーに戻ったとき、自動で再開するか「タップして測定を再開」が表示される
- [ ] ログアウトするとマイク使用中の表示が消える
- [ ] 許可を「許可しない」にすると「マイクの使用が許可されていません」と許可の変更方法が表示され、設定変更後に「もう一度試す」で開始できる
- [ ] 測定中に着信・Siri・別アプリでの録音があった場合、測定が止まり「タップして測定を再開」で復帰できる

### 7-2. 表示・精度

- [ ] 440 Hz の基準音で「A4（ラ）」「440.0 Hz」付近、基準 442 Hz では約 −8 cent・「低い」と表示される
- [ ] 基準を 440 Hz にすると、同じ音で ±3 cent 以内・「合っています」になる
- [ ] 音を止めると約1秒表示を保ってから「音を待っています」に戻り、グラフが減衰して消える
- [ ] 音を出した瞬間に大きく外れた値が一瞬表示されない
- [ ] 低音（コントラバス・チューバ等の C1～E2 付近）で音名とオクターブが正しい（iPhone マイクの低域特性で基音が弱い場合の挙動を記録）
- [ ] 高音（ピッコロの C7～C8 付近）で音名とオクターブが正しい
- [ ] 周波数グラフに基音マーカー（実線と周波数）、正しい周波数（破線）、倍音（▼）が表示される
- [ ] 空調・換気扇のみの環境で誤った音名が出続けない（出る場合は状況を記録）

### 7-3. 基準Hz・操作性

- [ ] 「−」「＋」が押しやすく、1 Hz ずつ変わり、測定中の表示がすぐ再計算される
- [ ] 430 Hz で「−」、450 Hz で「＋」が押せない見た目になる
- [ ] Safari を閉じて開き直しても基準Hzが復元される（プライベートブラウズでは 442 Hz に戻ってよい）
- [ ] 縦画面で横スクロールが出ず、音名・cent・判定が読みやすい
- [ ] VoiceOver で「基準周波数を下げる／上げる」と読まれ、音名の読み上げが連続しない

### 7-4. 負荷

- [ ] 5分間測定を続けて、表示の遅れ・発熱・電池消費が実用範囲か（体感と残量変化を記録）
- [ ] 測定中に画面が自動で消灯しない（Wake Lock 対応の iOS 16.4 以降）

### 7-5. 追加機能（判定方式・表示範囲・基準音再生）の確認について

7-1～7-4 の確認は測定のみの従来版に対するもので、以下の追加機能は含まない。テスト環境に今回の版を反映してから、以下を確認する。
準備: 7-1 と同じ手順でチューナーを開く。音源は実楽器、またはもう1台の端末で鳴らす基準音。iPhone は縦画面、ミュートスイッチはオフ、音量は中程度。

### 7-6. スペクトラムの表示範囲

- [ ] 初期表示が「倍音重視（500 Hz～16 kHz）」で、✓ が付いている
- [ ] 高い倍音（数 kHz の ▼ 目印）が縦画面で見分けられる
- [ ] 「全音域（25 Hz～16 kHz）」に切り替えると、低音の基音が表示され、測定は途切れない
- [ ] 倍音重視で低い音（例: A3 220 Hz）を鳴らしても、上部の音名・Hz は更新され、グラフに「◀ 基音 …Hz」が出る
- [ ] 周波数の目盛り・凡例・切り替えボタンが重ならない

### 7-7. 純正律モード

- [ ] 「純正律・長3度」「純正律・短3度」を選ぶと根音の欄が出て、初期値が C4（ド）になっている
- [ ] 「根音 C4 → 純正長3度 E4（目標 …Hz）」の表示で、何に対する判定かが分かる
- [ ] 目標の E を鳴らしたとき、主 cent が純正律の目標とのずれを示し、「平均律の E4 との差」がおよそ −14 cent になる（長3度）
- [ ] 別の音を鳴らしても目標が変わらない
- [ ] 根音・判定方式・A4 を変えると、表示がすぐ更新される
- [ ] 「平均律」に戻すと、最寄りの音での判定に戻る
- [ ] グラフの破線（純正律の目標）と点線（同じ音の平均律）が凡例と合わせて区別できる

### 7-8. 基準音の再生

- [ ] 初期状態は停止で、「再生する音：A4 = 442.0 Hz（音名で指定・…）」と表示される
- [ ] 「再生」で A4 が鳴り、音量 40 % が大きすぎない
- [ ] 再生開始・停止・音名変更・音量変更で「プツッ」というクリック音がしない（気になる場合は記録）
- [ ] 別の端末のチューナーで、再生音の周波数が表示値どおりか（例: 442.0 Hz、523.3 Hz）
- [ ] 「周波数（Hz）で指定」で 5000 や空欄を入れると理由が表示され、再生されない
- [ ] 純正律モードの「判定対象音を再生欄に設定」は押しても鳴らず、設定後に「再生」で鳴る
- [ ] 設定後に根音を変えても、再生欄の値が変わらない
- [ ] 再生中に A4 を変えると、音名指定のときだけ音の高さが変わる

### 7-9. 再生と測定の切り替え

- [ ] 再生中は「基準音を再生中」と表示され、マイク使用中の表示が消える
- [ ] 再生中の音が測定値として表示されない
- [ ] 「停止」後、測定が自動で再開する（許可やタップを求められた場合は、その案内どおりに再開できる）
- [ ] 停止直後に、基準音の残響が測定値として出続けない（0.25 秒の待ちで足りるか。出る場合は部屋・音量とともに記録）
- [ ] 再生中に着信・Siri があると再生が止まり、「タップして測定を再開」で戻れる
- [ ] 再生中にホーム画面へ戻る・別タブ・画面移動・ログアウトすると、音が止まる
- [ ] チューナー画面に戻っても基準音は勝手に鳴らない（測定だけ再開する）
- [ ] 再生中と測定中に画面が自動消灯しない（Wake Lock）。チューナーを離れたあとは通常どおり消灯する

### 7-10. VoiceOver・負荷

- [ ] VoiceOver で判定方式・表示範囲・指定方法の切り替えが「選択」状態とともに読まれる
- [ ] 「再生」「停止」、再生開始・停止、入力エラーが読み上げられる
- [ ] 音名や数値が連続して読み上げられない
- [ ] 判定方式・表示範囲を切り替えながら5分間測定し、表示の遅れ・発熱・電池消費が実用範囲か
- [ ] 基準音を5分間再生し、発熱・電池消費を記録する
