## 実装

### PERF-R08: 保留操作のない復帰ではactorを取得しない

`src/static/js/utils/portal_file_operations.js`

1. 認証済みであることを確認する。
2. ローカルの保留操作記録が空なら終了する。
3. 保留ありの場合だけサーバーのactor scopeを確認し、該当所有者の既存案内を表示する。

同じ認証所有者のactor取得は、実行中のPromiseだけを共有する。完了後は解除するため、
後の保存でサーバー確認を省略しない。保留操作ID、結果不明、所有者切替の保護は維持する。
壊れた保存記録は既存の警告経路へ進み、空記録へ書き換えない。

### PERF-R21: 保存済み音源URLと比較してYouTube確認を省略

`src/backend/services/extra_service.py`

- 新規登録時の検証は維持する。
- URL項目を含む更新は、保存済み行と比較する。クライアントの「変更なし」申告を信用しない。
- 同じURLなら外部確認を省略する。省略判断後、書込時の現在行でもURLが同じことを確認する。
- 比較後に別更新でURLが変わった場合は409とし、古いURLを上書きしない。
- 事前比較では非所有者で、コミット時に所有者になった場合も、未確認URLを保存せず409にする。
- 新しいURLは従来の検証を実行する。ネットワークI/Oは書込トランザクションの外で行う。
- URL項目を省略した更新では、現在行のURLを維持する。
  - API互換性の変更: 以前の省略時の空文字への置換から、既存URLの維持へ変更した。
    現行フロントはこの項目を送信するため、画面操作の挙動は変わらない。
- 所有者以外の投票は、現在行の他者の投票を保全する既存処理を維持する。

比較のため、URL項目を含む更新に保存済み行の事前読取が追加される。
今回確認した効果は外部確認の削減であり、SQL回数やDB時間の削減を主張するものではない。

### PERF-R23: 画像プレビューのObject URLを解放

対象: 本番チラシ、宣伝画像、団体アイコン。

- 各プレビューが所有するURLをappStateへ保持する。
- 画像の置換、選択解除、編集対象切替で旧URLを解放する。
- サーバーの画像URLは解放対象にしない。選択中のFileはプレビュー更新だけで失わない。
- 文書破棄時はブラウザの自動解放に任せる。グローバルなpagehideハンドラーは追加しない。
- 他機能が管理する`manifestObjectUrl`の処理は変更しない。
- DOMを保持するタブ移動では、戻ったときの表示とFileを維持するため解放しない。
- ダウンロード・録音再生・チューナー/メトロノームのURL処理は変更しない。

変更箇所: `portal_views.js`、`date_piece_promotion/api.js`・`state.js`、
`admin_system/render.js`。`common_helpers/pure.js`への変更はレビューで取り下げた。

## 再現方法

### ブラウザ計測

`scripts/perf_stage1_capture.cjs`を使用する。APIはすべて合成応答で、実DB/GCSへ接続しない。
既存E2E fixtureと実際の静的ファイルを使い、日時をJST 2026-10-21 12:00に固定する。

使用イメージ:

```text
mcr.microsoft.com/playwright:v1.61.1-noble
sha256:5b8f294aff9041b7191c34a4bab3ac270157a28774d4b0660e9743297b697e48
Node v24.17.0 / WebKit 26.5
```

環境変数:

| 変数 | 内容 |
|---|---|
| PERF_SOURCE_ROOT | 配信するソースルート。省略時は作業ディレクトリ |
| PERF_OUTPUT | report、HAR、画像、DOMの保存先 |
| PERF_ASSETS | Bootstrap 5.3.0の固定fixture保存先 |
| PERF_COMMIT | 対象ソースの識別記録 |
| PERF_IMAGE | 固定イメージの識別記録 |
| PERF_CAPTURE_ONLY=1 | 40回計測を省略し、表示・プレビューだけ取得 |

初回だけBootstrapの公開CSS/JSを取得し、以降は同じ保存済みバイト列を使用する。
そのSHA-256はreportへ記録する。fixture取得後はDockerの`--network none`でも実行できる。
HARは本文を保存せず、認証payload・認証ヘッダー・Cookieも除去する。

比較:

```powershell
node scripts/perf_stage1_compare.cjs `
  .tmp/perf-stage1-20261021/before-visual `
  .tmp/perf-stage1-20261021/after-visual `
  .tmp/perf-stage1-20261021/visual-comparison.json
```

比較スクリプトは環境・固定アセット・対象ケースの一致を先に検査し、画像/DOMの差分があれば失敗する。

### 希望曲の通信計測

```powershell
$env:PORTAL_PERF_REPORT='.tmp/perf-stage1-20261021/desired-after.json'
.venv/Scripts/python.exe -B -m pytest tests/backend/test_perf_stage1_measurements.py -q
```
