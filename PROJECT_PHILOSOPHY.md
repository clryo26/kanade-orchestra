# PROJECT_PHILOSOPHY.md

## Project Philosophy

オケポータル exists to help orchestra members, organizers, conductors, and staff spend less time fighting operational complexity and more time focusing on music.

It is not just a schedule tool, recording tool, or member list.

It is a shared operational foundation for an orchestra.

## Core Values

### 1. Music First

The system should reduce administrative burden so that people can focus on rehearsing, performing, listening, and enjoying music.

### 2. Kindness to Volunteers

Many community orchestra operations are supported by volunteers. The system should respect their time and reduce repetitive work.

### 3. Clarity Over Complexity

Information should be easy to find:

- When is the next rehearsal?
- What pieces are we rehearsing?
- Who is absent?
- Where is the recording?
- Which score should I download?
- What do I need to pay?

### 4. Long-Term Continuity

The system should remain understandable and maintainable years later.

Future maintainers, AI agents, and volunteers should be able to understand why the system works the way it does.

### 5. Safe Operations

Data should not disappear unexpectedly.

Important changes should be auditable.

Backups and restore procedures should exist.

### 6. Member-Friendly Design

The portal should work well on smartphones and should not require technical knowledge from members.

### 7. Admin-Friendly Design

Administrators should be able to manage information without touching code.

### 8. Scalable Design

The system should grow from one orchestra to many orchestras if needed.

### 9. Extensible Design

The system should eventually support:

- Stage layout generation
- AI practice summaries
- SNS draft generation
- Push notifications
- Multi-tenant operation
- Plugin-like feature additions

### 10. Respect Existing Work

Every feature added so far reflects real operational needs. Refactoring must preserve existing value.

## Long-Term Vision

オケポータル should evolve into an orchestra operations platform that can support:

- Community orchestras
- Amateur orchestras
- Wind ensembles
- Chamber groups
- Project-based ensembles

The final vision is not merely software.

It is infrastructure that helps musical communities continue, grow, and connect.
