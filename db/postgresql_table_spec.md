# PostgreSQL テーブル仕様書

最終更新: 2026-07-02
参照DDL: PostgreSQL schema（本番DBへ適用済み）

## 1. 共通仕様

- DBMS: PostgreSQL
- 文字列型: 原則 TEXT
- 主キー: 原則 `id BIGINT GENERATED BY DEFAULT AS IDENTITY`
- 監査列: 原則 `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`, `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
- 必須/任意の判定ルール:
  - 「必須」: `PRIMARY KEY` を構成する列、または `NOT NULL` が付与された列
  - 「任意」: 上記以外（NULL許容）の列
  - `DEFAULT` の有無は必須/任意の判定に影響しない
- 削除戦略:
  - 子を論理上保持不要: `ON DELETE CASCADE`
  - 参照元削除後も履歴保持: `ON DELETE SET NULL`
